# 萤灯拾光 · Firefly Lantern

一个关于「什么时候把光交出去」的九夜收集小游戏。

## 运行

直接用浏览器打开 `index.html`，或部署到任意静态站点（GitHub Pages 等）。

## 操作

- `WASD` / 方向键：移动
- `空格`：冲刺（短暂无敌）
- `E`：向附近萤灯注入星露
- 触屏：拖动移动，右下角冲刺 / 注入按钮

## 目标

九个夜晚逐夜变难：灯更多、荆棘挡路、暗潮减速、夜蛾追光。
点亮当前夜晚的全部萤灯即可进入下一夜，撑过九夜迎来「森林亮了」。

## 文件

- `index.html` 页面结构
- `style.css` 样式
- `game.js` 游戏逻辑
